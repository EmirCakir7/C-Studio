# C-Studio AI Models / Yapay Zeka Modelleri

---

### English
To enable the built-in offline AI Assistant in the **Slim Edition**, place a compatible GGUF model in this folder (`ai/models/`).

**Recommended Model:**
- **Model:** `qwen2.5-coder-1.5b-instruct-q3_k_m.gguf` (~881 MB)
- **Direct Download Link:**  
  [Download from Hugging Face](https://huggingface.co/Qwen/Qwen2.5-Coder-1.5B-Instruct-GGUF/resolve/main/qwen2.5-coder-1.5b-instruct-q3_k_m.gguf)
- **Repository:**  
  https://huggingface.co/Qwen/Qwen2.5-Coder-1.5B-Instruct-GGUF

Once downloaded, simply place the file inside this directory (`ai/models/`) and restart C-Studio. The IDE will automatically detect it and activate the offline AI assistant!

---

### Türkçe
**Slim (Hafif) Sürümde** dahili çevrimdışı Yapay Zeka Asistanını etkinleştirmek için, uyumlu GGUF modelini bu klasöre (`ai/models/`) yerleştirmeniz yeterlidir.

**Önerilen Model:**
- **Model:** `qwen2.5-coder-1.5b-instruct-q3_k_m.gguf` (~881 MB)
- **Doğrudan İndirme Bağlantısı:**  
  [Hugging Face Üzerinden İndir](https://huggingface.co/Qwen/Qwen2.5-Coder-1.5B-Instruct-GGUF/resolve/main/qwen2.5-coder-1.5b-instruct-q3_k_m.gguf)
- **Model Sayfası:**  
  https://huggingface.co/Qwen/Qwen2.5-Coder-1.5B-Instruct-GGUF

İndirdiğiniz `.gguf` dosyasını bu klasöre (`ai/models/`) yapıştırıp C-Studio'yu yeniden başlatın. C-Studio modeli otomatik olarak algılayıp asistanı hemen kullanıma hazır hale getirecektir!
